# قالب CI، بدون تغییر تنظیمات موجود مخزن

این پوشه یک قالب پیشنهادی است و workflow فعال GitHub نیست. برای حفظ محدودهٔ
افزودنی، تنظیمات موجود و مسیر فعال انتشار مخزن دست‌نخورده می‌مانند.

مرحلهٔ کنترل در محیط تمیز باید در پوشهٔ `ERP_School` این فرمان‌ها را اجرا کند:

```sh
pnpm install --frozen-lockfile
pnpm check
```

نیازها: Python 3.11+، Node.js 22.12+، pnpm 11.25.0. دسترسی workflow فقط خواندن
کد است؛ هیچ secret مدرسه، پایگاه دادهٔ واقعی، deploy یا push به main لازم ندارد.
فعال‌سازی بعدی باید در یک تغییر مشخص و قابل بازبینی انجام شود.
