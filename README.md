# Mohamad Jahedi Almas — Personal Landing Page

A responsive bilingual (Persian/English) personal portfolio built with plain HTML, CSS, and JavaScript.

## Publish with GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` to the repository root.
3. Open Settings → Pages.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Wait for the published URL to appear.

## Before publishing
- Review all dates and descriptions against your latest résumé.
- The résumé listed some project URLs only partially; only complete URLs were included.
- Personal phone number, street/neighborhood address, age, marital status, military status, and salary were intentionally omitted for privacy.
- Check whether you want your email address publicly visible.
